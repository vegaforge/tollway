# In-browser 402 playground

Added a browser-only playground to the docs site for decoding and validating x402 and Tollway payment headers, inspecting signed payment summaries, verifying Tollway receipts against pasted public keys, and encoding sample challenges. Pasted values stay in the browser.

The page intentionally does not fetch live challenges or wire dashboard data. XDR parsing is loaded only when requested so it does not affect the initial page bundle.
