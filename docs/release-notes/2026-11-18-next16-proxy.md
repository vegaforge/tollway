# Next.js 16 proxy paywall

The Next adapter peer range includes Next 16 and adds `paywallProxy` for route groups. The proxy strips caller-supplied receipt headers, forwards the gate's schema-checked receipt to the route handler, and retains `PAYMENT-RESPONSE` on the response.
