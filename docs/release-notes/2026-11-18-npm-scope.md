# Packages are named @vegaforge/tollway-*

The `@tollway` scope on npm belongs to an unrelated project, so Tollway's
packages are renamed into the vegaforge organisation's own scope:
`@tollway/core` is now `@vegaforge/tollway-core`, `@tollway/server` is
`@vegaforge/tollway-server`, and so on for all eleven packages. The private
apps follow the same pattern (`pnpm --filter @vegaforge/tollway-demo start`).

Nothing has been published under either name. Versions stay where they are,
and publishing remains a manual step on `main` after the current Drips Wave.

Decision: ADR-2026-11-18-npm-scope.
